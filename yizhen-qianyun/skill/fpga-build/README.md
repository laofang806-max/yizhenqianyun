# 固件构建
适用范围：当前RTL构建、资源/时序报告、版本与交付核对。

## 使用方法
在支持技能的助手中输入：`$fpga-build 基于当前源码构建带摄像头固件，记录SHA256、资源和时序，不下载。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：工程XPR、RTL/XDC、器件、工具版本、构建参数。输出：bit、完整日志、timing/utilization/DRC/IO与源文件哈希。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
隔离工程读到旧绝对路径；复用旧bit冒充本次结果；时序通过却遗漏未约束外设路径。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
color-reset-stability-20261031实际Vivado实现；camera-resource-comparison-20261030两种配置报告。时序正裕量不等于硬件长稳。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
