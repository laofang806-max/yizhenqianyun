# 一针千韵：设计与交付说明

电脑侧负责文字生成图片、上传/拍摄、白底排除、近似颜色合并、针迹规划及逐层串口传输。
FPGA 侧负责串口解析、双轴 STEP/DIR、编码器反馈、OV5640 相机数据流及红外闭环针周期。
固定兔子/蝴蝶等图案保存已审定路线，普通图片继续使用可选路径算法。
最终板卡模式来自 fpga - 副本，board_top 默认自动下针，并非历史无反馈版本。

## 证据边界

当前模型小样本诊断不代表通用湘绣生成精度；模型运行在 PC GPU。
RTL 仿真通过不等同机械实测通过。当前构建信息看 build/validation.json 与 build/release。
静态时序报告不代表全部外设电气时序已实测验证，针脉冲仍需按实际机构调节。
