# 太极直径60mm（6cm）固定针序与数据流

在图案创建窗口输入“太极”“太极图”“太极6cm”或“太极60mm”，点击“使用生成图”，自动载入331针路线。
默认画框100×100mm，图案居中，图像比例2/3（界面显示66.7%），太极外圆编码后宽高均60.00mm。
保持1600STEP/mm时，直径对应96000 STEP。改变图像缩放、画框尺寸、旋转、针点或电机标定将改变实际传输数据。
JSON/BIN/UART三种文件均由项目真实导出与编码函数生成；串口数据COLOR black 676，共331条S、345条J，6181字节。
已逐点核对所有S的累计目标与预览针点一致，BIN解码往返一致，动作数低于4096且位移均符合int16限制。
TXT是115200 8N1串口协议数据，不是bit流。使用上位机正常“发送黑色路径”即可发送同样的默认针序。
照片/普通上传仍按用户之前要求生成花鸟；太极通过上述文字图案入口载入，避免把普通照片入口改成另一张图。
黑色区域稀疏直线填充，填充线只在两端落针，曲线保留必要分针；连接上方黑点的线段也会绣出。
固定针序仅确保软件规划与编码一致，实际尺寸和效果仍取决于驱动细分、机械标定、编码器与针线配合。
本次未向板卡缓存或启动任务，没有重新烧录固件。
