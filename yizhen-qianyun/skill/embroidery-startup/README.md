# 环境启动
适用范围：上位机、相机桥接、USB设备与端口占用排查。

## 使用方法
在支持技能的助手中输入：`$embroidery-startup 打开上位机并启动真实相机桥接，复用已有服务。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：项目根目录、4173/8765监听状态、Windows设备枚举。输出：可访问的网站/桥接状态、日志位置和剩余问题。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
COM被其他进程占用；USB Slave未接；误用JTAG端口；桥接退出但网页仍显示连接入口。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
用户实际遇到COM访问拒绝、桥接未启动和USB Slave暂未连接；检查助手只读，不制造相机帧。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
