# 本项目观察形成的排查清单
| 触发条件 | 排查方法 | 判定边界 |
|---|---|---|
| 预览正确、滑台位置错误 | 对照STEP/mm、ENC增量、轴向与尺量；查差分原点 | 不能只修预览或直接归咎路径 |
| 无声无运动 | 查22V、驱动锁定、STEP/DIR真实接线、任务READY | 本项目曾实际发现22V未开和接线错误；不推定每次都相同 |
| ERR feedback且三灯亮 | 看ENC是否变化、轴接线与反馈方向，再看纠偏状态 | ERR证明到位检查失败，不唯一定位原因 |
| 复位后串口无响应 | 区分蓝色核心RESET清临时配置与任务RESET | 不能反复重启掩盖固件状态 |
| COM访问拒绝 | 枚举端口占用与其他脚本/网页连接 | 不直接杀未知进程 |
| 资源图差距异常 | 核对摄像头开关、器件分母、综合/实现阶段与文件哈希 | 无摄像头构建不是仅拔USB摄像头 |
| 仿真名称乱码或波形太密 | 使用实际信号名、可用字体、radix和局部时间缩放 | 不手画预期信号冒充仿真结果 |
| RTT看起来始终很低 | 核对超时与pending、上传暂停、保留窗口 | 只统计成功响应会掩盖失联 |
