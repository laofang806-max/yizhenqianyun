# 固定图案管理
适用范围：用户明确指定花鸟、鸟、花、太极固定图案。

## 使用方法
在支持技能的助手中输入：`$artwork-route 载入太极路线，保持外圆约60mm，导出当前针序。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：指定图案、目标尺寸、路线JSON及参考图。输出：参考图与针序配套文件、实际尺寸、资产路径和摘要。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
默认缩放改变直径；静态针数失效；文件扩展名与实际解码不匹配。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
太极6mm更正为6cm、单鸟独立路线、上传照片不应被无条件替换成预设的实际需求。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
