# 单轴校准
适用范围：小行程单轴脉冲/编码器/尺量对照。

## 使用方法
在支持技能的助手中输入：`$motion-calibration 准备X轴前进2mm、不返回、不下针的校准方案，先不启动。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：轴、距离、返回要求、STEP/mm、编码器基线、当前固件。输出：缓存文件或准备方案、目标与实测对照表、偏差判断。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
22V未开；驱动接线错；轴接反；闭环追加脉冲；复位后逻辑原点改变。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
本项目2mm测试中22V未开与驱动接线错误的实际排查。现有1600STEP/mm和500计数/mm仅为当前机械参数，移植必须重核。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
