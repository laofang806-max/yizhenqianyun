# 单鸟连续短路线（2026-10-29）

使用相同的单鸟图稿，重新规划为284针、284个不同的0.01mm落针坐标。图案约48×34mm，画框100×100mm。针迹线长约378.8mm，上一版本442针约501.7mm。回走与邻近针点尽量错开约0.2mm；这只是计划坐标间距，不代表实际针孔必然完全分离。

允许起点与终点不同，不为强行闭合额外回走。沿已有轮廓和羽毛线覆盖图案，连接断开的细节时仅添加短线；这些短线也会实际绣出。实心鸟眼为两圈小螺旋，回走时尽量沿原线错开针孔。

与上一版相比，少158针（约35.7%），计划线长少约24.5%。若使用每针1秒停留固件，仅停留时间就少158秒；加减速、到位检查、纠偏和运行条件另计，不承诺总耗时精确下降同一比例。

算法先建立线稿中心线图，移除小于约0.4mm的骨架毛刺，将鸟眼作为螺旋路径连接，再用短连接线连通。通过两个虚拟端点与最小权完美匹配求出这张固定图上的最短开放邮差遍历，之后简化和落针离散化。这里“最短”仅针对已经选定的中心线与连接图，不是所有线稿解释、所有连接方法或所有刺绣工艺下的全局最优。线稿提取、连接选择及错孔仍有近似。

路径文件与上位机使用同一套毫米坐标转换与串口增量格式。仍需重新上传才会替换板卡缓存；本轮未自动上传或启动任何运动，也未改固件。按此前要求不运行额外仿真/回归套件。

预览圆点均对应真实S落针指令；动画按实际针序推进。机器最终自动返回软件原点是针抬起的非刺绣移动，不计入图中线迹。

本次只是改规划，不代表已修复机械定位。预览正确但实物偏移时，仍需核对物理原点、X/Y方向、1600STEP/mm、500计数/mm和机械传动。
