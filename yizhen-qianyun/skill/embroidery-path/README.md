# 针迹规划
适用范围：线稿连续走线、填充、尺寸与针孔优化。

## 使用方法
在支持技能的助手中输入：`$embroidery-path 将输入图规划为60mm图案，保留鸟眼，说明连接线及重复针孔。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：图像、画框尺寸、针距、填充方式、是否允许回走。输出：预览、标准化路径、尺寸/针数统计、JSON和UART一致性结果。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
反光/阴影造成误分割；过度去噪删除眼睛；单笔强连跨白区；毫米与厘米混淆。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
花鸟局部叶片轨迹与单鸟眼睛保留的用户反馈；现有pathExport/deviceProtocol流程。几何正确不代表实绣效果。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
