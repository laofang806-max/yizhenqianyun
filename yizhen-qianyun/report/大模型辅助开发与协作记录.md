# 一针千韵：作者工作与大模型辅助记录

项目由作者主导推进。作者结合实际刺绣需求确定作品方向、硬件条件、功能取舍和操作流程，
通过现场操作与问题反馈推动系统改进。OpenAI Codex 用于代码、测试和文档辅助。

## 作者主导的工作

1. **总体方案与功能设计**：确定非遗刺绣数字化方向，提出图案输入、针迹生成、串口传输、双轴运动和自动下针的完整流程，明确各阶段的功能要求。
2. **硬件选型与系统集成**：提供并确认达芬奇 Pro、OV5640、TB6600、步进电机、编码器和 ITR9606 等硬件资料与连接条件，承担实际接线、机构装配及现场调试工作。
3. **刺绣工艺与路径要求**：确定图案、尺寸和颜色处理要求，提出忽略白底、合并近似色、逐层发送、减少落针、缩短跳线、标注首针及保留固定针序等改进。
4. **针控方案与操作约束**：确认最高点透光、3.3V 下针触发和回针检测方式，提出未回针补发、任务复位等要求，并指定最终采用自动下针版本。
5. **模型实验与软件迭代方向**：确定 SDXL 白底花鸟输出目标，提出模型训练、结构改进、loss 与性能图需求；确定登录、模型选择、语音输入和数据查看等上位机功能。
6. **现场反馈与作品交付**：反馈相机连接、串口、路径生成及实际刺绣中的问题，推动多轮修订；确定提交目录、简介、演示材料和复现说明等交付要求。

## 大模型辅助的工作

Codex 根据作者提出的需求和硬件条件，协助编写、修改上位机与针控代码，处理针迹数据，
配置模型实验并生成图表，执行软件测试、RTL 仿真和 Vivado 构建，整理接线说明与提交材料。
硬件连接和机构操作由作者进行，实际机械效果由作者现场确认。
