# 传输数据检查
适用范围：离线检查动作流、针序、编码范围和导出一致性。

## 使用方法
在支持技能的助手中输入：`$embroidery-protocol-check 检查本地UART文件，累计每个S目标并与标准JSON比较，不连接设备。`
不支持技能的工具可直接读取同目录 SKILL.md 并按流程执行。
输入：UART文本、标准JSON、STEP/mm、对应固件版本。输出：动作数、落针数、尺寸、重复目标、错误定位。
项目路径变更时将SKILL.md中的Control路径映射到自己的工程，先检查实际代码版本；工具路径为本机示例。

## 失效条件与排查
超过4096动作；int16溢出；仅看WRITE_OK；layer被当作第五种固定线色。出现这些情况时停在可定位的检查步骤，说明缺少的证据，不以修改展示掩盖底层问题。

## 经验来源与已验证范围
动作拆分、差分坐标与最新layer协议的现有源码；check_uart.py仅做结构/目标检查，不代替实际TS编码器或实板测试。
这些是本项目观察与实现记录，非通用硬件保证；新工程必须重新运行对应检查。
